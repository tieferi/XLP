# XLP - Excel Learning Projects

XLP is a simple learning-card application for Mac. Its interface is minimalist, and the learning view is designed to look like a learning card. It is controlled using the Space bar and Enter. The aim is to keep the focus on the learning content. Learning data is stored openly in Excel workbooks and can be edited directly.

XLP is written in Java.

## Download

[XLP-1.0.0.dmg](https://github.com/tieferi/XLP/releases/download/1.0.0/XLP-1.0.0.dmg)

## How can XLP be used?

1. **Just get started:** All you need to do is enter your vocabulary in an Excel list and link the list in the application. The Quick Start Guide explains everything you need to know.

2. **Configure XLP individually:** Many aspects of the appearance and behavior can be customized if needed. The User Manual explains how to do this.

3. **Use Excel templates:** The provided Excel templates can be used to create fully configured learning projects with a double-click.

## Requirements

XLP runs on macOS 11 (Big Sur) or later on both Intel and Apple Silicon processors. No separate Java installation is required. The application is notarized by Apple.

Learning data is stored in Excel workbooks. An application capable of opening and editing .xlsx files is therefore required to create or modify learning data.

## Installation

To install XLP, double-click the DMG file and drag the app onto the Applications folder.
